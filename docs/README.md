# Документация подготовки Calculandia к продакшену

Дата фиксации исходного состояния: **15 июля 2026 года**.

Этот каталог содержит актуальный результат технического, SEO- и UX-аудита проекта. Старый файл [`audit.md`](../audit.md) сохранён как историческое описание первоначального замысла и не должен использоваться как отчёт о фактически реализованном состоянии.

## Комплект документов

1. [`audit/2026-07-15-production-readiness.md`](audit/2026-07-15-production-readiness.md) — проверенное состояние кода, сборки, зависимостей, базы, домена, SEO, безопасности и эксплуатации.
2. [`research/2026-07-15-competitors-ux-seo.md`](research/2026-07-15-competitors-ux-seo.md) — конкурентное исследование, визуальное сравнение и требования к UX/UI и адаптивности.
3. [`architecture/production-target-and-roadmap.md`](architecture/production-target-and-roadmap.md) — предлагаемая информационная и техническая архитектура, каталог первого релиза, шаблоны страниц и дорожная карта.

## Как читать статусы

- **Факт** — подтверждено кодом, командой, HTTP-проверкой или визуальным просмотром.
- **Вывод** — интерпретация подтверждённых фактов.
- **Предложение** — целевое решение; оно ещё не реализовано и может быть скорректировано до начала соответствующего этапа.
- **P0** — блокирует безопасный публичный запуск.
- **P1** — требуется для первого SEO-ready релиза.
- **P2** — можно выполнять после запуска на основании реальных данных.

## Итоговый статус

На дату аудита проект **не готов к публикации**. Реалистичный срок до первого индексируемого релиза при сохранении качества — **7–10 рабочих дней**. Предлагаемый первый релиз: 12–15 полноценных калькуляторов, четыре устойчивые категории, корректная техническая индексация и отсутствие рекламы до первого полезного результата.
