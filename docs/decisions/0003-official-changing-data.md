# ADR-0003: официальные изменяемые данные

- Статус: **Accepted**
- Дата: 2026-07-15

## Контекст

Baseline обещает учёт праздников РФ, но использует неполный hardcode и не учитывает перенесённые рабочие субботы. Runtime API зависит от внешнего сервиса и PostgreSQL.

## Решение

Калькулятор рабочих дней исключён из launch manifest. Разница календарных дат и прибавление периода не называют результат рабочим/официальным сроком.

Рабочие дни могут войти в следующую волну только при наличии version-controlled набора календарей поддерживаемых лет, сформированного из официальных постановлений Правительства РФ и проверенного golden cases. Для каждого года обязательны:

- `effectiveYear`;
- официальный первичный source URL и номер акта;
- `sourceCheckedAt`;
- явные нерабочие и перенесённые рабочие дни;
- SHA/версия набора;
- поведение `unsupported year` без догадок или автоматического fallback.

Внешний сервис может использоваться только как инструмент сверки при сборке данных, но не как единственный production source.

## Последствия

Первый релиз полностью статичен и не требует holiday API/БД. Нельзя показывать флаг «учитывать праздники РФ» до прохождения отдельного data gate.
