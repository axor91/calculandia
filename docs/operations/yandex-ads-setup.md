# Включение рекламы РСЯ и замер eCPM

Код интеграции готов и выключен. Здесь — что сделать владельцу, чтобы реклама
появилась на сайте, и как снять с неё цифру. Решение и его границы —
[`../decisions/0008-yandex-advertising-network.md`](../decisions/0008-yandex-advertising-network.md).

## 1. В кабинете РСЯ

1. Добавить площадку `calculandia.ru` и дождаться модерации.
2. Создать два блока RTB — они встанут на страницах калькуляторов после
   калькулятора и после статьи. Формат — адаптивный; высота слота на странице
   рассчитана на 250 px, более высокий блок тоже встанет, просто раздвинет
   страницу при появлении.
3. Скопировать идентификаторы блоков. Они выглядят как `R-A-123456-1`.
4. Взять строки ads.txt: **Настройки → Общие → ads.txt**.

## 2. Включение на сайте

Задать три repository variables в GitHub (`Settings → Secrets and variables →
Actions → Variables`, репозиторий `axor91/calculandia`):

| Переменная                     | Значение                                     |
| ------------------------------ | -------------------------------------------- |
| `YANDEX_RTB_CALCULATOR_TOP`    | идентификатор первого блока                  |
| `YANDEX_RTB_CALCULATOR_BOTTOM` | идентификатор второго блока                  |
| `YANDEX_ADS_TXT`               | строки ads.txt; несколько строк — через `\n` |

Это не секреты: идентификаторы блоков и ads.txt публичны по своей природе.

Дальше — обычный релиз: merge в `main` → workflow `release` соберёт артефакт уже
с рекламой → `deploy` выкатит. Отдельных действий на сервере не требуется.

Значения подставляются **на сборке**, поэтому смена переменной без нового
релиза ничего не изменит.

## 3. Проверка после выката

```bash
curl -s https://calculandia.ru/ads.txt | head            # строки на месте
curl -s https://calculandia.ru/kalkulyator/skidka | grep -c yandex_rtb_   # 2
curl -sI https://calculandia.ru/ | grep -i content-security-policy | grep -c yandexadexchange   # 1
```

Открыть страницу калькулятора в браузере и увидеть объявления своими глазами:
блоки могут не заполниться сразу после модерации, это нормально.

## 4. Замер eCPM

Цель — узнать, сколько сеть платит за тысячу показов на этом трафике, чтобы
считать экономику g-post.ru и 101skill.ru по факту, а не по обещаниям сетей.

- Смотреть в кабинете РСЯ: **Статистика → по площадкам**, показатель eCPM по
  дням и по блокам отдельно.
- Первую неделю данные шумные: заполнение растёт по мере обучения сети.
  Разумный горизонт для вывода — 3–4 полные недели.
- Сопоставлять с посещаемостью из Метрики (счётчик 111212984): доход за период
  делить на визиты, чтобы получить понятную величину «рублей за визит».
- Отдельно смотреть верхний и нижний блок: разница между ними скажет, стоит ли
  вообще ставить рекламу под статьёй на других сайтах.

## 5. Выключение

Очистить те же переменные и выпустить релиз. Сайт вернётся к состоянию без
рекламы полностью: без загрузчика, без контейнеров, без ослаблений CSP, и
раздел о рекламе исчезнет с публичной страницы конфиденциальности.
